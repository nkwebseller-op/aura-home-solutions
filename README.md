## 💓 Key Features

#### ₨₯ Firebase Contact Form
- Form data saves automatically to Firebase Realtime Database
- Success toast notification + auto-open WhatsApp with inquiry details
- Validation: name, email, phone, service, message
- Fallback: Firebase fail → direct WhatsApp open

#### 🛾️ Contact & Good Plan Cards
- Google Rating badge (5.0 | 9 Reviews)
- Call, WhatsApp, Office Location cards with hover effects
- Google Maps Embed (Saheed Nagar, Bhubaneswar)
- Working Hours card

#### 🕄 Main PERFORMANCE Team Designers
- Lazy loading for all images and videos
- Preconnect for CDNs (Google Fonts, Font Awesome, Firebase)
- Minified CSS with custom properties
- Google Map iframe deferred until scroll
- Deferred Firebase/Typed.js initialization
- Reduced motion preference respected

#### 📡 SEO Optimization
- **Schema.org LocalBusiness** structured data
- Open Graph (The Graph) meta tags
- Twitter Card meta tags
- Canonical URL + sitemap.xml
- robots.txt
- Apple mobile web app capable

- Typed.js text animation in hero
- 11 section scroll-reveal animations
- Counter animations in statistics
- Testimonial marquee carousels (2 directions)
- Timeline dot animations with check effect
- Mouse parallax on hero circular image
- Hover effects on all cards and buttons
- Gold pulse animation on hero frame
